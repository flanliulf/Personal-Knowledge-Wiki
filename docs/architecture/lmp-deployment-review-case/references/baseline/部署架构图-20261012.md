## 用户决定（User Decisions）

1. 业务用户经 `Internet → WAF → Ingress / NGINX` 访问；这些外网连接均使用 `HTTPS / TCP 443`。
2. 运维人员经 `HTTPS / TCP 443` 访问“运维入口 / 堡垒机”，不经过 VPN。保留堡垒机到 K8S 的管理连接，移除该连接的协议与端口待确认标签。
3. 图中只表达 LMP 部署于一个 VPC，以及业务与数据两个 Subnet；删除 VPC ID 和全部 CIDR。图中移除网络路由与放通规则待确认说明。
4. K8S 标题明确使用腾讯云 TKE。腾讯云 SaaS 产品分别使用 TC ADP（腾讯云智能体平台）与 COS（腾讯云对象存储）名称。
5. API Gateway 服务端口为 8182；LMP Backend 为 12001。短链服务、Data Platform、Superset 的目标端口分别为 9868、7002、8081，均使用 HTTP。后三个服务由外网 Ingress / NGINX 直接代理，不画成必须经过业务 Gateway。内部应用之间调用使用 HTTP；未单独指定端口的内部服务按用户最新确认统一使用 8090，已明确端口保留。
6. 企微出站为 `HTTPS / TCP 443`，经过受控 NAT；NAT 节点不包含防火墙。客户外部系统、企微 API / 会存 SDK、原生回调与 API / SSO 均为 `HTTPS / TCP 443`。
7. PostgreSQL 为 `TCP 5432`；Elasticsearch 会存索引为 `HTTP / TCP 9200`；文件存储为 `HTTPS / TCP 443`；RocketMQ 协议按用户指定为 HTTP。RocketMQ 保留原 UAT 登记接入端口 8080，并区分图示协议口径与未运行验证的 SDK / 接入事实。
8. Secret / 配置节点继续移除。平台 / 标品使用 `lmp-uat.vgcserv.com.cn` 与 `lmp-prod.vgcserv.com.cn`；独立短链的 UAT 与 PROD 域名均为 `idunyx-vw.com`。短链公开解析和跳转机制仍未核验，不补造 302、TTL 或失效页。

9. 图中移除全部待核验、待确认等不定性描述。所有虚线改为实线，图例同步说明。外部 SaaS 节点分别显示“TC ADP / 腾讯云智能体平台”和“COS / 腾讯云对象存储”。这项展示调整不表示已完成客户环境运行验证。
