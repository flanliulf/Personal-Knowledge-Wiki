# Changelog（变更记录）

## [1.1.0] - 2026-09-26

- 将两份写作指南的选定上游原文和许可文件原样收录到 Skill 包内，入口改为直接按任务读取原文及示例。
- 将原写作规则摘要改为适用顺序与差异说明，新增 Agent 写作自检、可选 `autocorrect` 流程和来源记录。
- 保持无安装依赖；自动排版仅在工具可用、目标获授权时使用，真实宿主行为仍待验证。

## [1.0.1] - 2026-09-26

- 区分用户写作要求和技术事实证据，明确冲突时的处理。
- 按用户指定或目标文件既有格式交付，不再限定 Markdown。
- 仅在目标项目存在适用 `AGENTS.md` 时读取；缺失不阻塞写作。

## [1.0.0] - 2026-09-26

- 创建中文技术文档写作与定点修订流程，覆盖 README、设计文档、接口说明和教程。
- 加入事实核验、简明写作、目标项目优先及两份上游指南冲突处理规则。
- 提供文档类型检查清单；当前为 KnowledgeWiki 源包，尚未安装或完成真实宿主行为验证。
