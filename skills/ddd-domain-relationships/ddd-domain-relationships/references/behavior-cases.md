# 行为用例（Behavior Cases）

## 执行记录（Execution Record）

以下为虚构输入和待执行验收设计，全部 `NOT_CHECKED`。编写及静态审阅不算宿主执行。真实执行需记录宿主及版本、Skill 版本/hash、输入、预期、实际输出、状态和证据位置；遵守用户授权，不为测试修改生产资料。

## 触发与依赖边界（Trigger and Dependency Boundaries）

REL-01 是直接请求，REL-02 是关系历史的同义请求，REL-04 是关键输入缺失，REL-05 是只读边界，REL-08 检查超范围交接。另以“替我直接创建生产外键”核对不应进入本分析 Skill 的写入流程；无法读取用户资料时须报告具体缺口，核心不可分析则 blocked，不用课程文件或外链图填项目事实。以上触发及依赖边界同样未执行。
