# Changelog（版本记录）

## [1.0.0] - 2026-09-09

### Added（新增）

- 单 Skill 的教师公开信息调研、逐条核验及师资团队分析工作流。
- 研究总约束、A–D 来源分级、五种事实状态和身份冲突隔离。
- 任教时间线、班型、班主任经历分型、教学风格与成果边界。
- 可演进事实库契约、纠错影响追踪、报告和 JSON 模板。
- 虚构反例与行为用例、原方案映射。

### Limitations（限制）

- 采用 base profile，中文单入口；不附固定 MCP 配置、自动抓取脚本或真实性评分器。
- 静态检查与真实宿主行为验证分开记录；尚未安装或执行真实教师调研。
- 粘贴方案是设计输入，所述真实人物案例未在本次创建中独立核验，不进入研究事实库。
