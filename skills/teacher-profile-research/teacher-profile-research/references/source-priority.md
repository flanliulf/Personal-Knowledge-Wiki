# Source Priority（来源优先级）

## Search Order（检索顺序）

1. 确认学校全称、校区与可验证官网入口；优先学校师资介绍、任命通知、年级报道、公开课和班主任记录。
2. 检索教育主管部门、教科院、大学、竞赛组织方的相关名单和原始公告。
3. 查可信媒体的采访与报道，追溯引用材料。
4. 用转载、公开个人文章和用户材料补线索；回到可核实原来源。

## Query Patterns（查询构造）

以下是替换输入的查询示意，不是需要原样执行的命令：

- `学校全称 姓名 学科`
- `site:已确认官方域名 "姓名"`
- `"姓名" "班主任" 年份`
- `"学校全称" "姓名" "高三"`
- `"姓名" "公开课" 学科`
- `"姓名" "竞赛" "指导教师"`
- `"班级原称" "年级" 年份 学校全称`

分别覆盖履历、轨迹、任教年级与角色、班型、公开教学案例、教研、竞赛及成果。先广泛定位身份，再对缺口定向检索，不穷举无关词。

## Source Reading（正文读取）

先读标题、发布者、日期及人物段落前后的标题和表格表头，再抽取最短充分证据。PDF 或图片必须核对页面与视觉归属，OCR 仅作辅助，辨认不清即保持未验证。遇登录、失效、付费或访问限制，记录失败原因，可查合法公开转载；不声称已读原文。

搜索工具给出的概述、问答聚合、名师库无出处字段只登记为线索。引用应链接到支持结论的具体页面；不以搜索结果页链接替代原文。

## Search Log（检索日志）

逐次记录时间、person_id、目标 claim 或缺口、查询/已读地址、结果 source_id、独立原始来源组、访问障碍和下一步。日志可用简表，不存不必要的全文、凭据或学生资料。

每个缺口默认完成官方渠道、相关活动/主管机构渠道和一次独立公开检索；连续两轮针对性补查无新增有效证据即停止该缺口。此预算仅表示检索范围，不证明穷尽。记录未覆盖项；用户有时限时优先身份和关键 claim。
