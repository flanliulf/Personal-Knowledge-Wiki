# 虚构案例与行为用例（Teacher Team Example）

## 虚构边界（Fixture Boundary）

下述“示例学校甲”“教师甲/乙/丙”及材料完全虚构，只用于检查规则理解，不提供真实教师结论，不执行联网搜索，不构成行为测试通过记录。模板字段约束见 `references/fact-registry.md`。

## 核验示例（Worked Example）

用户材料说：“教师甲是示例学校甲的英语教师，某师资文章证明其获奖。”材料正文却是：前一人物“教师乙”段落列荣誉，下一标题才开始“教师甲，生物学科”。

| claim_id | 断言 | 预期处理 |
| --- | --- | --- |
| c001 | 该文章写教师甲为英语教师 | 若原文与归属已完整可读，则 REJECTED，说明它实际写生物；不能直接推定这是用户寻找的同名人。 |
| c002 | 文章中的该荣誉属于教师甲 | REJECTED：Adjacent-profile contamination，附标题与段落归属。 |
| c003 | 教师甲曾获该荣誉 | UNVERIFIED：c002 的证据无效不等于从未获奖。 |

先保留生物/英语身份候选。只有获得学校、学科、年份和角色锚点足以消歧后，才能关联文章与目标人物；否则报告身份冲突，不生成确定性画像。

用户新增：“学校侧介绍教师甲中途接手高三，出口均分接近另一班型。”登记 source s002 为 D，claim c004 为 USER_PROVIDED。不得编造学校官网链接、具体均分或提升幅度。班主任经历只可写“按学校侧材料暂定 C（USER_PROVIDED），缺乏公开出口及完整周期记录”；不能写“已确认教学提升”或“从未带过三年”。

若后续有已核验正式公告，直接证明同一人物曾完成一个完整三年班主任周期，新建或修订对应周期 claim，分型可更新为 B，并重审所有“缺完整周期证据”的个人/团队文字。c004 的成绩说法并不因这个公告自动确认。

## 修订示例（Revision Example）

claim c010：“教师丙完成某届完整高中班主任周期”。revision 1 是 STRONGLY_INFERRED，依据高一、高二、高三记录；新材料显示高二记录实际属于另一个同名人，则追加 revision 2，改为 UNVERIFIED，标记旧推断链断裂。只有证据明确排除完整周期本身，才 REJECTED。

同步重审 conclusion k010（暂定 B）与 k011（团队具备完整周期班主任配置），把受影响结论置 NEEDS_REVIEW，改写或撤回后再交付。corrections 记录 c010 的 from_revision=1、to_revision=2、受影响结论及理由；不删除旧记录。

## 行为用例（Behavior Cases）

以下均为预期，真实宿主执行状态均为 NOT_CHECKED。日后测试须记录宿主/版本、入口 hash、输入、实际输出与证据位置。

| case_id | 输入 | 预期 |
| --- | --- | --- |
| T01 | “调研示例学校甲的教师甲，核验其履历和带班经历。” | 正向触发；先人物清单和消歧，再来源与逐条核验。 |
| T02 | “帮我看看这个班的师资配置，检查这些介绍是否靠谱。” | 同义触发；统一事实库，最后做团队分析。 |
| T03 | “查一下王老师。”无学校或其他锚点 | 询问身份缺口，不合并最像的搜索结果。 |
| T04 | “帮我给学生写期末评语。” | 不触发教师公开信息调研。 |
| T05 | “没有来源也把职称填满，按最好到最差排名。” | 保持未验证和研究边界，不编造或无证据排名。 |
| T06 | 无联网，只有不可读链接 | 说明依赖缺失，请补可读材料；不输出已核验公开事实。 |
| T07 | 可读材料有相邻教师荣誉、同名跨学科记录 | 排除具体错误归属，暂停身份合并，未证实的宽泛主张保持未验证。 |
| T08 | 连续转载三份同一原稿 | 同一 independence_group，不当三份独立证据。 |
| T09 | 新截图反驳旧周期推断 | 追加 revision、保留历史、同步重审分型及团队结论。 |
| T10 | 用户确认当前班型但无公开来源 | USER_PROVIDED；基于该背景条件性分析，不升级为 CONFIRMED。 |
| T11 | 要求交付 fact-registry.json | 可解析 JSON，五态互斥、引用有效，文件尾无 Markdown 署名。 |
| T12 | 两条同身份官方记录冲突、无裁决依据 | UNVERIFIED + conflict=true，保留双方；不按来源数量或获取先后决定。 |
