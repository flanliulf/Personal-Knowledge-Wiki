# AutoCorrect Workflow（自动排版检查）

## Scope（使用边界）

`autocorrect` 只辅助检查中英文间距、标点等排版。它不能核实技术事实、改进结构或判断语气。仅在宿主已有可用命令且目标文件在用户授权范围内时使用；不为执行本 Skill 自动安装工具。先读目标项目已有配置，避免覆盖其排版约定。

## Steps（执行步骤）

1. 用 `command -v autocorrect` 确认命令可用，必要时用 `autocorrect -V` 记录版本。没有命令时跳过工具，按两份包内指南手工检查。
2. 对授权的单个目标文件运行 `autocorrect --lint <file>`，检查报告中的具体位置。只读审阅到此为止，不运行 `--fix`。
3. 写作或修改任务需要自动修复时，先复制目标文件到保留 `.md` 扩展名的临时位置，对副本运行 `autocorrect --fix <copy>`。比较修复前后的差异，只把符合[指南适用顺序](writing-rules.md)、落在授权段落内的修改应用到目标文件。不要对整个仓库或未经授权的文件运行 `--fix`。
4. 人工复核技术标识、代码块、链接、数字、引号、破折号、省略号和目标项目自有格式。第一份指南允许的统一写法不能仅因工具或第二份指南提示而判错。若工具建议改变了含义、正式名称、第一份指南的明确写法或范围外文本，不应用该建议。
5. 交付时写明工具是否可用、运行的检查与修复范围，以及仍需人工复核的项目。`--lint` 无报告不等于事实和写作质量已验证。

## Reference（工具来源）

命令形式参考 [AutoCorrect 官方仓库](https://github.com/huacnlee/autocorrect)。实际使用前以本机安装版本的帮助输出为准；版本和选项不符时停止工具步骤并改为手工检查。
