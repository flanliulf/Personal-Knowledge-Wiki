## 状态解释（Status Definitions）

| 状态 | 含义 | 删除依据 |
| --- | --- | --- |
| `readable` | 已有记录取得对应内容。实际阅读范围另列。 | 不是删除依据。 |
| `dead` | 原路径明确 404，复查仍 404。 | 本清单中只有 B41 满足既有确认条件。 |
| `restricted` | 付费、验证码、安全验证或访问拒绝。 | 不能按失效删除。 |
| `uncertain` | 连接、证书、路由、资源身份或正文范围未确认。 | 不能按失效删除。 |
| `verification_pending` | 没有保留下该项独立核验记录。 | 不是访问失败或删除依据。 |

`original_link_status` 描述原地址；`resource_status` 或 `retrieved_resource_status` 描述实际取得的资源。两者可以不同。例如 B50 的迁移后文章可读，但旧 hash 地址仍待核验。

访问状态与采用范围分别记录。`cited_subset` 表示正文只引用相关部分；`review_pending` 表示已登记输入，但未按当前方案重新判断采用范围。未在正文引用的来源，不沿用旧审计的广泛采用标记。
